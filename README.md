One funny single-line one-star review from a house cat about its human,
116 characters:

> One star. He dragged a tree inside, hung shiny balls on it, then acted shocked when I climbed it. False advertising.

The joke: the human decks a tree with shiny balls — an open invitation
by cat logic — then acts shocked when the cat climbs it. The closer,
"False advertising", is the deadpan verdict of a disgruntled customer:
the review genre itself delivers the sting. The premise appears nowhere
in the field of 399 entries — no box vs bed, no bowl moved two inches,
no laptop keyboard, no 3 a.m. bowl, no sunbeam, no red dot, no "filed a
complaint with the dog".

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
byte-identical on every run. Python 3.13, standard library only, no network.
